# ระบบตรวจจับรถฝ่าไฟแดง (YOLO11 + Webcam)

ไฟล์เดียว `index.html` รันได้ทั้งหมดในเบราว์เซอร์ (ไม่ต้องมี backend) โดยใช้:
- **onnxruntime-web** รันโมเดล YOLO11 (.onnx) เพื่อตรวจจับ รถยนต์ / มอเตอร์ไซค์ / คน
- **Chart.js** สร้างกราฟสรุปผล
- **Tesseract.js** อ่านป้ายทะเบียนแบบ OCR (best-effort)

## 1) เตรียมโมเดล YOLO11 (.onnx)

ต้อง export เองจาก Ultralytics เพราะไฟล์โมเดลไม่สามารถแนบมาให้ได้:

```bash
pip install ultralytics
yolo export model=yolo11n.pt format=onnx imgsz=640
```

จะได้ไฟล์ `yolo11n.onnx` — นำไปวางไว้ **โฟลเดอร์เดียวกับ index.html**
(หรือแก้ path ในช่อง "Path ไฟล์โมเดล" บนหน้าเว็บ)

> โมเดลมาตรฐาน (coco) รู้จักคลาส `car` (2), `motorcycle` (3), `bus` (5), `truck` (7), `person` (0) อยู่แล้ว — เพียงพอสำหรับ demo นี้

## 2) รันผ่านเว็บเซิร์ฟเวอร์ (สำคัญ)

เปิดไฟล์ตรงๆ แบบ `file://` จะใช้กล้อง (getUserMedia) และโหลดโมเดลไม่ได้เพราะข้อจำกัดของเบราว์เซอร์
แนะนำ:
- VSCode: ติดตั้ง extension **Live Server** แล้วคลิก "Go Live"
- หรือ `python -m http.server 8000` แล้วเปิด `http://localhost:8000`

## 3) วิธีตั้งค่าในหน้าเว็บ

1. กด **เปิดกล้อง**
2. กรอก/ยืนยัน path โมเดล แล้วกด **โหลดโมเดล**
3. กด **ลากเส้นจอดใหม่** แล้วคลิก-ลากบนภาพให้ตรงกับเส้นหยุดจริง
4. (ทางเลือก) กด **กำหนดกรอบสัญญาณไฟ** แล้วลากครอบดวงไฟจราจรในภาพ เพื่อให้ระบบเดาสีไฟอัตโนมัติ — หรือจะกดปุ่ม **ตั้งไฟแดง/ตั้งไฟเขียว** เองด้วยมือก็ได้ (แนะนำสำหรับความแม่นยำสูงกว่า)
5. กด **ตั้งค่าระยะอ้างอิง** แล้วลากเส้นทับระยะที่ทราบความยาวจริง (เช่น ความกว้างเลนถนน) และกรอกค่าความยาวจริงเป็นเมตรในช่อง "ระยะอ้างอิงจริง" — ใช้คำนวณความเร็ว (v = Δระยะทาง/Δเวลา)
6. ปรับ **เกณฑ์ความเร็วขั้นต่ำ**: รถที่ข้ามเส้นด้วยความเร็วต่ำกว่าค่านี้ (ชะลอ/คืบ) จะไม่ถูกนับว่าฝ่าไฟแดง
7. อัปโหลดเสียงแจ้งเตือนของตัวเอง หรือใช้เสียง beep เริ่มต้น

เมื่อไฟแดง + มีรถ/มอเตอร์ไซค์ข้ามเส้นด้วยความเร็วเกินเกณฑ์ → ระบบจะ:
- เล่นเสียงแจ้งเตือน
- บันทึกภาพ + เวลา + ประเภทรถ + สีรถ (โดยประมาณ) + ผลอ่านป้ายทะเบียน (OCR) + ความเร็วที่ประเมินได้ ลงตาราง Log
- อัปเดตกราฟสรุปผล (รายชั่วโมง / ตามประเภทรถ)
- ข้อมูล log เก็บใน `localStorage` ของเบราว์เซอร์ (ดูย้อนหลังได้แม้ปิดหน้าเว็บแล้วเปิดใหม่) และ export เป็น CSV ได้

## 4) แก้ไขโค้ดเอง

ไฟล์ `index.html` มีคอมเมนต์แบ่งเป็นส่วนๆ ชัดเจน (ส่วนที่ 1–15) แก้ค่าตัวแปรใน `CFG` และ `state`
ที่ด้านบนของ `<script>` ได้โดยตรง เช่น เกณฑ์ต่างๆ, คลาสที่สนใจ, สีธีม (ปรับใน `:root{...}` ของ CSS)

มีแผง debug (แถบสีแดงด้านล่างจอ) ที่จะโชว์ error ที่เกิดขึ้นแบบเรียลไทม์ ช่วยให้ debug ใน VSCode ได้ไวขึ้น
(หมายเหตุ: ระบบไม่ได้ "แก้บั๊กอัตโนมัติ" ให้เองจริงๆ — แนะนำใช้ error message ตรงนี้ร่วมกับ GitHub Copilot / Claude ใน VSCode เพื่อช่วยแก้ไข)

## 5) ข้อจำกัดที่ควรทราบ (สำคัญ)

- **OCR ป้ายทะเบียน** และ **การตรวจสอบหมวกนิรภัย** ในไฟล์นี้เป็นเพียงตัวอย่างเริ่มต้น (heuristic) ความแม่นยำในสภาพแสง/มุมกล้องจริงจะต่ำ
  สำหรับใช้งานจริงควร fine-tune โมเดลแยกเฉพาะ (เช่น ป้ายทะเบียนไทย, การตรวจจับหมวกนิรภัย) แล้วเสียบเข้ามาแทนฟังก์ชัน `ocrPlate()` และ `checkHelmet()`
- การประเมิน**ความเร็ว**อาศัยการคาลิเบรตระยะบนภาพ 2 มิติ → มีความคลาดเคลื่อนหากมุมกล้องเอียงมาก แนะนำติดตั้งกล้องตั้งฉากกับถนนให้มากที่สุด
- การตรวจจับสีไฟจราจรอัตโนมัติ (auto-light) เป็นการเทียบค่าสีเฉลี่ยแบบง่าย ควรใช้ปุ่มตั้งไฟด้วยมือหากต้องการความแม่นยำสูงสุด
- **ข้อกฎหมาย/ความเป็นส่วนตัว**: ระบบนี้เก็บภาพ ป้ายทะเบียน และข้อมูลที่อาจระบุตัวบุคคลได้ หากนำไปใช้งานจริงบนถนนสาธารณะ ควรตรวจสอบให้สอดคล้องกับกฎหมายคุ้มครองข้อมูลส่วนบุคคล (PDPA) และได้รับอนุญาตจากหน่วยงานที่เกี่ยวข้องก่อนติดตั้งใช้งานจริง
